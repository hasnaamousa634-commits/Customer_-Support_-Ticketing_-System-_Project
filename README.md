# Customer Support Ticketing System

## Project Description
The Customer Support Ticketing System is a system designed to help organizations manage customer complaints and inquiries efficiently. It allows customers to submit support tickets and enables support staff to track, manage, and resolve them.

## Project Objectives
- Organize customer complaints and inquiries.
- Track the status of support tickets.
- Improve communication between customers and support staff.
- Reduce the time needed to resolve customer problems.
